# Changelog

## 2026-11-11
### Added
- MiniMax Global as a TTS-only Cloud Voice provider.
- Support for MiniMax `speech-2.8-turbo` and `speech-2.8-hd`.
- MiniMax HTTP T2A v2 synthesis with MP3 hex decoding, voice ID selection, speed control and basic emotion mapping.
- Real TTS key validation and regression tests for MiniMax.
- Persian Cloud Voice guide and README updated.

### Preserved
- Existing Google AI Studio, Groq and ElevenLabs providers.
- Existing local Edge TTS and Windows speech fallbacks.
- Existing independent STT configuration and chat Route Manager.
