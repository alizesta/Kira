# تشخیص گفتار محلی Kira با whisper.cpp و Vulkan

## ترتیب موتورهای تشخیص

1. Qwen3-ASR 0.6B موتور اصلی فعلی است.
2. whisper.cpp Vulkan در صورت نبودن Qwen، خطای بارگذاری، خروجی خالی یا خروجی ردشده به‌عنوان hallucination استفاده می‌شود.
3. faster-whisper روی CPU با int8 آخرین fallback است؛ اگر Vulkan runtime نصب نباشد یا درایور هیچ دستگاه Vulkan گزارش نکند نیز این مسیر فعال می‌شود.

هیچ صدای میکروفن به سرویس ابری یا API ارسال نمی‌شود.

## نصب موتور Vulkan

در تب صدا، بخش تشخیص گفتار (STT)، گزینه زیر را انتخاب کن و «نصب مدل انتخاب‌شده» را بزن:

whisper.cpp Vulkan · large-v3-turbo-q5_0 (AMD GPU)

نصب‌کننده این دو جزء را به پوشه داده‌های Kira می‌گیرد:
- بسته runtime ویندوز x64 با backend Vulkan (حدود 16 MiB)
- مدل چندزبانه ggml-large-v3-turbo-q5_0.bin (حدود 574 MiB)

هر دو دانلود با SHA-256 ثابت اعتبارسنجی می‌شوند. فایل‌های runtime از انتشار pinned پروژه fahrim/whisper-vulkan-win و مدل از ggerganov/whisper.cpp دریافت می‌شوند. مسیر داده‌ها خارج از پوشه نصب برنامه است.

## اجرای امن

- سرور فقط روی 127.0.0.1 و یک پورت آزاد موقت اجرا می‌شود.
- فرایند فرزند توسط Kira ساخته و در پایان عمر Listener متوقف می‌شود.
- درخواست HTTP فقط به loopback ارسال می‌شود؛ دسترسی شبکه محلی یا اینترنتی برای سرور باز نمی‌شود.
- فایل WAV از آرایه float32 در حافظه ساخته می‌شود و روی دیسک موقت نوشته نمی‌شود.
- اگر runtime یا Vulkan GPU در دسترس نباشد، Kira به faster-whisper CPU برمی‌گردد.
- مدل Qwen همچنان اولویت اول باقی می‌ماند و نصب Vulkan آن را حذف یا جایگزین نمی‌کند.

## مدل و سخت‌افزار

مدل انتخابی multilingual و مناسب ورودی فارسی است. نسخه Q5 برای کاهش حجم مدل انتخاب شده؛ کیفیت و سرعت نهایی باید با نمونه‌های واقعی فارسی و لهجه کاربر سنجیده شود. GPU شناسایی‌شده در لاگ موتور ثبت می‌شود. پشتیبانی Vulkan به درایور GPU وابسته است.
