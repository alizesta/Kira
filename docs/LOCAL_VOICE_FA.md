# موتورهای صوتی محلی

تمام ورودی و خروجی گفتار Kira به‌صورت محلی پردازش می‌شود؛ هیچ صدای میکروفن یا متن TTS به Google، Edge، Windows SAPI یا Providerهای ابری ارسال نمی‌شود.

- **STT اصلی:** Qwen3-ASR 0.6B، اجرا به‌صورت محلی.
- **STT پشتیبان:** faster-whisper، اجرا به‌صورت محلی.
- **TTS:** Piper، با صدای فارسی Mana یا فایل ONNX انتخاب‌شده.
- **پخش صدا:** از خروجی انتخاب‌شده در ویندوز؛ این فقط پخش فایل WAV محلی است، نه موتور گفتار ویندوز.

## نصب و آماده‌سازی

برای نصب تازه، `install.bat` را اجرا کن. نصب‌کننده:
- وابستگی‌های ضبط و پخش صدا را نصب می‌کند.
- Qwen3-ASR، faster-whisper و Piper را نصب می‌کند.
- مدل Qwen و صدای فارسی Piper را دانلود و برای اجرای محلی آماده می‌کند.

برای نصب یا تعمیر فقط موتورهای صوتی در محیط موجود:

```powershell
.venv\Scripts\python.exe scripts\setup_local_voice.py --install --prepare-models
```

دانلود اولیه‌ی بسته‌ها و وزن مدل‌ها به اینترنت نیاز دارد؛ بعد از آماده‌شدن مدل‌ها، تشخیص و تولید گفتار روی سیستم خودت اجرا می‌شوند. وزن‌ها و کش‌ها در مسیر داده‌ی پایدار Kira نگه‌داری می‌شوند، نه پوشه‌ی موقت برنامه.

## انتخاب موتور و تست

در تب «صدا و میکروفون»:
- زبان و مدل Whisper محلی پشتیبان را انتخاب کن.
- حساسیت و میکروفن ورودی و بلندگوی خروجی را تنظیم کن.
- در «مدل‌های Local»، Qwen3-ASR و Piper را مستقل فعال یا غیرفعال کن.
- از دکمه‌های «تست STT» و «تست TTS» برای آزمایش هر مسیر استفاده کن.

## رفتار هنگام خطا

- اگر Qwen3-ASR در دسترس نباشد یا متن خالی برگرداند، Kira فقط سراغ faster-whisper محلی می‌رود.
- اگر Whisper محلی نصب یا آماده نباشد، خطای روشن نمایش داده می‌شود؛ هیچ سرویس آنلاین جایگزین نمی‌شود.
- اگر Piper آماده نباشد یا خروجی WAV معتبر نسازد، خواندن پاسخ با خطا متوقف می‌شود؛ هیچ صدای ابری، Edge یا SAPI استفاده نمی‌شود.

مدل‌های چت (Ollama یا Providerهای API) مستقل از این مسیر هستند. استفاده از API برای چت، به معنی ارسال صدای میکروفن یا متن TTS به آن Provider نیست.
