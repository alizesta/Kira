# موتورهای صوتی محلی

Kira دو موتور مستقل و صرفاً صوتی دارد:

- **تشخیص گفتار (STT):** Qwen3-ASR 0.6B، اجرا روی CPU.
- **تولید گفتار (TTS):** Mana Persian Piper از بستهٔ `persian-speech`.

این‌ها مدل چت نیستند و جای مدل مکالمه را نمی‌گیرند.

## نصب و آماده‌سازی کامل مدل‌ها

۱. ابتدا `install.bat` را اجرا کنید تا محیط اصلی Kira ساخته شود.

۲. سپس فایل **`install_local_voice.bat`** را از پوشهٔ اصلی Kira اجرا کنید. این فایل:
- وابستگی‌های صوتی را داخل همان `.venv` نصب می‌کند.
- وزن‌های Qwen3-ASR را از Hugging Face دریافت و در کش محلی آماده می‌کند.
- موتور Mana Piper را اجرا می‌کند و یک WAV آزمایشی می‌سازد.
- اگر هر مرحله شکست بخورد، خطای همان مرحله را چاپ می‌کند.

دانلود اولیهٔ مدل‌ها به اینترنت و چند گیگابایت فضای آزاد نیاز دارد. تمام داده‌های پایدار Kira، از جمله تنظیمات، تاریخچهٔ چت، پشتیبان‌ها، کش مدل‌های Hugging Face و فایل‌های صوتی، در مسیر زیر نگهداری می‌شوند:

`A:\Project KIRA\Kira Attachments`

زیرپوشه‌های مهم:
- `huggingface` — وزن‌های Qwen و مدل‌های Hugging Face
- `voice_cache` — فایل‌های صوتی تولیدشده
- `cache` — کش‌های PyTorch، pip و runtime
- فایل‌های تنظیمات و پایگاه‌دادهٔ چت — مستقیماً در ریشهٔ همین پوشه

این مسیر مستقل از پوشهٔ نصب Kira است؛ بنابراین جایگزینی یا آپدیت ZIP باعث دانلود دوبارهٔ مدل‌ها نمی‌شود. اگر درایو A در دسترس یا قابل‌نوشتن نباشد، Kira برای جلوگیری از متوقف‌شدن برنامه از `%LOCALAPPDATA%\Kira` استفاده می‌کند.

اگر فقط نصب بسته‌ها را می‌خواهید، در پوشهٔ اصلی پروژه اجرا کنید:

```powershell
.venv\Scripts\python.exe scripts\setup_local_voice.py --install
```

برای آماده‌سازی مجدد وزن مدل‌ها:

```powershell
.venv\Scripts\python.exe scripts\setup_local_voice.py --prepare-models
```

## مدیریت از داخل Kira

در تب «صدا و میکروفون»، بخش «موتورهای صوتی محلی فارسی»:
- وضعیت نصب و بارگذاری Qwen و Piper را ببینید.
- هر موتور را مستقل فعال یا غیرفعال کنید.
- با «بارگذاری Qwen» مدل تشخیص گفتار را در حافظه بارگذاری کنید.
- با «تست صدای فارسی» تولید و پخش صدای Piper را امتحان کنید.

توجه: نصب بستهٔ Python به‌تنهایی به معنی دانلودشدن وزن مدل نیست. فایل `install_local_voice.bat` هر دو مرحله را انجام می‌دهد.

## اولویت و fallback

- STT: Qwen3-ASR محلی ← Whisper محلی (اگر نصب باشد) ← Cloud Voice ← Google.
- TTS: Persian Piper محلی ← موتورهای صوتی قبلی Kira.

در صورت شکست موتور محلی، Kira باید به موتور بعدی برود؛ مسیرهای صوتی قبلی حذف نشده‌اند.
