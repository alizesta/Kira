# موتورهای صوتی محلی

Kira از دو موتور مستقل و صرفاً صوتی استفاده می‌کند؛ هیچ‌کدام مدل چت نیستند:

- STT: Qwen3-ASR 0.6B، اجرای CPU و پشتیبانی از فارسی.
- TTS: Mana Persian Piper از بستهٔ `persian-speech`، خروجی WAV فارسی و اجرای CPU.

## نصب
در اجرای `install.bat`، نصب موتورهای صوتی محلی در مرحلهٔ جداگانه پرسیده می‌شود؛ چون وابستگی‌های Qwen ممکن است چند گیگابایت دانلود داشته باشند. اگر آن مرحله را رد کردید، در پوشهٔ اصلی پروژه و با محیط Kira فعال اجرا کنید:

```powershell
.venv\\Scripts\\python.exe -m pip install -r requirements-voice-local.txt
```

بسته‌های Python داخل `.venv` همان نصب Kira قرار می‌گیرند. کش مدل‌های Hugging Face به‌صورت پیش‌فرض در `%LOCALAPPDATA%\\Kira\\huggingface` ذخیره می‌شود و با حذف یا جایگزینی پوشهٔ پروژه باقی می‌ماند. مسیر سفارشی `HF_HOME` نیز حفظ می‌شود.

وزن‌های Qwen و مدل صدای Piper در اولین استفاده دریافت/آماده می‌شوند. بعد از آماده‌شدن مدل‌ها، تبدیل صدا به متن و متن به صدا محلی است و صدایی به Cloud Voice ارسال نمی‌شود.

## مدیریت از داخل Kira\nدر تب «صدا و میکروفون»، بخش «موتورهای صوتی محلی فارسی» وضعیت نصب و بارگذاری Qwen و Piper را نشان می‌دهد. از همان‌جا می‌توان هر موتور را مستقل فعال/غیرفعال کرد، مدل Qwen را دستی بارگذاری کرد و خروجی Piper را با یک جملهٔ فارسی شنید. بررسی وضعیت، مدل‌ها را بارگذاری نمی‌کند؛ اولین تست یا استفادهٔ واقعی ممکن است دانلود چندگیگابایتی Qwen را آغاز کند.\n\n## اولویت و fallback مستقل
- STT در کد فعلی: Qwen3-ASR محلی ← Whisper محلی (در صورت نصب) ← Cloud Voice ← Google (آخرین fallback).
- TTS: Persian Piper محلی ← Cloud Voice ← Edge TTS ← صدای Windows SAPI.

شکست STT فقط مسیر STT را به مرحلهٔ بعد می‌برد؛ شکست TTS نیز فقط روی TTS اثر دارد. Voice Engine فعلی، ضبط میکروفون، VAD، پخش، توقف، lip-sync و Cloud Voice حفظ می‌شوند.

این بسته‌ها اختیاری‌اند تا نصب اصلی Kira به وابستگی‌های سنگین PyTorch/Transformers گره نخورد. برای نصب روی ویندوز، محیط Python 3.12 توصیه می‌شود؛ سازگاری نسخه‌های دیگر باید جداگانه بررسی شود.
