# Kira Documentation

This directory contains the technical and operational documentation for Project Kira.

## Documentation language policy

English is the primary source language. Every new document is written in English first, then translated into Persian in a matching `_FA.md` file. The root project overview follows the same convention with `README.md` and `README.fa.md`.

For existing documents, both language files are kept side by side. Update the English source first and then synchronize the Persian translation in the same change set. Do not delete a translation or an older technical record merely because another file becomes the preferred entry point.

## Documentation maintenance rules

1. Write the complete English document first.
2. Review and approve the English source, then write the Persian translation in the matching `_FA.md` file.
3. Keep headings, section order, links, technical identifiers, file paths, commands, limits, and warnings aligned.
4. Do not translate code identifiers, configuration keys, command names, API names, or literal file paths.
5. When implementation changes, update both languages in the same change set; update the English source first.
6. Do not claim a feature is implemented unless the source code or a test supports it.
7. Preserve historical reports as historical snapshots. Do not present historical test statements as current verification.
