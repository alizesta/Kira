# عامل فایل (T5-A)

کد: `kira/tools/fileagent.py`، ثبت‌شده در Tool Registry (دسته‌ی `files`). بدون وابستگی جدید.

## ابزارها
| ابزار | سطح | کار |
|---|---|---|
| `make_folder` | ۲ (بدون تأیید) | ساخت یک پوشه‌ی جدید |
| `create_file` | ۲ | ساخت فایل متنی جدید با محتوا (حداکثر ۲۰۰KB) |
| `append_text` | ۲ | افزودن متن به انتهای فایل متنی ساده (پاراگراف جدید در خط جدید) |
| `copy_item` | ۲ | کپی فایل یا پوشه (سقف ۳۰۰۰ فایل / ۵۰۰MB؛ لینک و فایل‌های حساس کپی نمی‌شوند) |
| `rename_item` | ۲ | تغییر نام یک مورد در همان پوشه |
| `write_file` | ۳ (تأیید) | جایگزینی کامل محتوا؛ قبلش `.bak-<زمان>` کنار فایل ساخته می‌شود |
| `delete_folder` | ۳ | انتقال پوشه به سطل بازیافت (پوشه‌های اصلی Desktop/Documents/... حذف نمی‌شوند) |
| `batch_files` | ۳ | کپی/انتقال/حذف چند مورد (حداکثر ۵۰). اگر یکی از مقصدها هم‌نام باشد، **هیچ کاری** انجام نمی‌شود |
| `organise_folder` | ۳ | مرتب‌سازی فایل‌های سطح اول پوشه به زیرپوشه‌ها بر اساس نوع (Images, Documents, ...) یا ماه |
| `undo_file_operation` | ۳ | برگرداندن آخرین عملیات (تا ۱ ساعت): ساخت، کپی، تغییر نام، انتقال، افزودن، نوشتن، مرتب‌سازی و عملیات گروهی |

ابزارهای قبلی (`search_files`، `list_folder`، `file_info`، `read_file`، `delete_file`، `move_file`، `open_path`) بدون تغییر ماندند.

## قواعد امنیتی (در کد، نه در پرامپت)
- همه‌ی مسیرها از `PathPolicy` می‌گذرند: فقط پوشه‌های مجاز، هیچ فایل حساس (کلید، رمز، `.env` ...)، هیچ‌وقت داده‌ی خود Kira یا AppData/Windows.
- **هیچ چیز بی‌صدا رونویسی نمی‌شود.** ساخت/کپی/تغییر نام/انتقال روی مورد هم‌نام خطا می‌دهد.
- ابزارهای سطح ۲ فقط وقتی اجرا می‌شوند که **پیام همین نوبت کاربر** درخواست تغییر داشته باشد (ساخت، کپی، تغییر نام، بنویس ...)؛ متن یک فایل یا صفحه‌ی وب نمی‌تواند Kira را به نوشتن وادار کند.
- فایل جدید یا نام جدید هرگز پسوند اجرایی/اسکریپت (exe, bat, ps1, lnk, js ...) نمی‌گیرد؛ نام باید قوانین ویندوز را رعایت کند (CON، `:`، نقطه‌ی آخر ...).
- بعد از هر عملیات وجود و اندازه روی دیسک بررسی می‌شود و همان نتیجه‌ی واقعی گزارش می‌شود.
- عملیات برگشت‌پذیر در `kira_file_ops.json` (پوشه‌ی داده) ثبت می‌شود.

## محدودیت‌ها
- حذف و برگرداندن «ساخت/کپی» از سطل بازیافت ویندوز استفاده می‌کند؛ فقط روی Windows کار می‌کند.
- Word/PDF با این ابزارها نوشته نمی‌شود (T5-C).
- مرتب‌سازی فقط سطح اول پوشه را می‌بیند و زیرپوشه‌ها را دست نمی‌زند.

## نیاز به اعتبارسنجی روی Windows 11
1. ساخت پوشه با نام فارسی در Documents (و OneDrive اگر Documents منتقل شده) و فایل داخلش.
2. حذف پوشه و `undo` ساخت/کپی از سطل بازیافت واقعی.
3. انتقال بین دو درایو (`shutil.move`) و مسیرهای طولانی.
4. رفتار با فایل باز در برنامه‌ی دیگر (قفل بودن) هنگام rename/write.
