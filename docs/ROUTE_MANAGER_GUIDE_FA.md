# راهنمای Route Manager

باز کردن: منوی ☰ ← **Route**.

## مفاهیم
- **API / Provider**: یک اتصال با کلید (Groq، Mistral، Google AI Studio، Cloudflare، OpenRouter، سفارشی) یا Ollama محلی. APIها را با **Add API** در بالای همین صفحه اضافه می‌کنی (راهنما: `API_MANAGER_FA.md`).
- **Route**: یک مدل روی یک Provider. هر Route تنظیمات و اولویت خودش را دارد.
- **اولویت = ترتیب فهرست.** Route بالاتر زودتر امتحان می‌شود؛ اگر خراب بود (Failover) نوبت بعدی است.

## کارهای روزمره
| می‌خواهم... | کار |
|---|---|
| ترتیب را عوض کنم | Route را بکش و رها کن، یا ▲ ▼ |
| مدلی را موقت خاموش کنم | Route را انتخاب کن ← تیک «فعال» را بردار (تنظیماتش می‌ماند) |
| مدل پیش‌فرض را انتخاب کنم | Route ← «پیش‌فرض» (به رتبه‌ی ۱ می‌رود) |
| همین حالا از مدل مشخصی استفاده شود | Route ← «استفاده‌ی دستی»، یا کلیک روی نشانگر کنار فیلد پیام. برگشت: «خودکار» |
| بدانم مدل سالم است | «تست اتصال» (ممکن است کمی از سهمیه‌ی API مصرف کند) |
| سرعت مدل‌ها را مقایسه کنم | «Benchmark این Route» یا «Benchmark همه‌ی فعال‌ها» |
| مدل‌های Ollama نصب‌شده را بیاورم | «یافتن مدل‌های Ollama» (Routeهای جدید غیرفعال‌اند؛ خودت فعال کن) |
| Failover را خاموش کنم | تیک Failover (آن‌وقت فقط Route انتخاب‌شده‌ی دستی امتحان می‌شود) |

## تنظیمات هر Route
- **Timeout**: حداکثر انتظار. ابری ۵ تا ۶۰ ثانیه (پیش‌فرض ۱۸)، محلی ۱۰ تا ۶۰۰ (پیش‌فرض ۱۸۰).
- **Cooldown بعد از خطا**: چند ثانیه این Route بعد از خطای موقتی (شبکه/Timeout/5xx) کنار گذاشته شود (پیش‌فرض ۴۵؛ ۰ = بلافاصله دوباره). خطای ۴۲۹ حداقل ۳۰ تا ۶۰۰ ثانیه (طبق Retry-After) و خطای کلید/مدل ۶۰ ثانیه استراحت دارد. با ذخیره‌ی تنظیمات یا انتخاب دستی، Cooldown پاک می‌شود.
- **Context / Num Predict** (فقط Ollama): ۰ یعنی مقدار پیش‌فرض Provider. توجه: اگر دو Route با **یک مدل** ولی Context متفاوت داشته باشی، Ollama هنگام جابه‌جایی مدل را دوباره بارگذاری می‌کند.

## وضعیت سلامت
`— بدون تست` ، `● سالم` (آخرین درخواست/تست موفق)، `◐ مشکل موقت` (Timeout/شبکه/5xx)، `✕ خراب` (کلید/مدل نامعتبر، Ollama خاموش). وضعیت فقط در حافظه است و با ری‌استارت پاک می‌شود.

## نشانگر مدل
قبل از ارسال مدلی که **اول** امتحان می‌شود را نشان می‌دهد؛ هنگام پاسخ مدل واقعی؛ بعد از پایان مدل نهایی (با Failover همان مدل جایگزین). کلیک ← جزئیات / انتخاب دستی.

## ذخیره
تب Route خودکار ذخیره می‌کند. کلید خالی در کادر یعنی «کلید قبلی بماند».
