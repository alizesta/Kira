# معماری Kira

**مرجع فعلی معماری:** [مستند جامع معماری](ARCHITECTURE_MASTER.md)

این فایل مدخل کوتاه معماری فارسی است. جزئیات مستقل یا ادعاهای موازی دربارهٔ معماری ایجاد نمی‌کند؛ مراجع پیوندشده منبع اصلی هستند.

## اسناد مرجع معماری

۱. [معماری جامع](ARCHITECTURE_MASTER.md) — ساختار فعلی تأییدشده، ترکیب زمان اجرا، جهت وابستگی‌ها و مرزهای زیرسامانه‌ها.

۲. [مالکیت ماژول‌ها](MODULE_OWNERSHIP.md) — مسئولیت ماژول‌ها، قراردادهای عمومی، وابستگی‌های مجاز و اتصال‌های ممنوع.

۳. [نقشهٔ راه معماری](ARCHITECTURE_ROADMAP.md) — بدهی فنی تأییدشده، تصمیم‌های استخراج و گام‌های مهندسی به‌ترتیب.

۴. [گزارش تحویل پیاده‌سازی معماری](ARCHITECTURE_IMPLEMENTATION_HANDOFF_2026-11-18.md) — شواهد پیاده‌سازی و فهرست بازبینی.

## اصل همگام‌سازی

مستندات معماری باید با کد شاخهٔ کاری همگام بمانند. وجود یک توصیف در مستند به‌تنهایی اثبات نمی‌کند که کد اجرا شده یا در محیط واقعی پذیرفته شده است. تست‌های خودکار، اجرای GUI ویندوز، سخت‌افزار صوتی و بررسی عملکرد باید جداگانه تأیید شوند.
