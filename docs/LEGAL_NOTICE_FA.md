# اطلاعیه حقوق مالکیت فکری و شرایط استفاده از Project Kira

**وضعیت: اختصاصی — تمامی حقوق محفوظ (All Rights Reserved)**  
**انتساب فعلی صاحب پروژه در GitHub: `alizesta`**  
**سال انتشار این اطلاعیه: ۲۰۲۶**

> این سند یک اطلاعیه و متن پایه برای اعلام موضع حقوقی پروژه است؛ جایگزین بررسی و تنظیم قرارداد توسط وکیلِ آشنا با کشور محل اقامت و محل فعالیت صاحب حقوق نیست. هویت حقوقی و مالکیت هر جزء باید پیش از انتشار عمومی نهایی تأیید شود.

## ۱. اعلام مالکیت و دامنه حقوق

کد منبع اصیل، طراحی‌ها، ساختار و سازمان‌دهی اختصاصی، مستندات تألیفی، متن‌ها، رابط کاربری، گرافیک‌ها و سایر آثار قابل حمایت که به‌طور مستقل برای Project Kira ایجاد شده‌اند، در حدودی که قانون قابل اعمال حمایت می‌کند، تحت حقوق پدیدآورندگان و صاحبان قانونی آن آثار قرار دارند.

این مخزن هیچ مجوز عمومی، رایگان، ضمنی یا دائمی برای استفاده از اجزای اختصاصی Project Kira صادر نمی‌کند. مگر آنکه اجازه‌ای جداگانه و کتبی از صاحب حق مربوط دریافت شود، تمامی حقوقی که صراحتاً واگذار نشده‌اند محفوظ می‌مانند.

این اعلامیه ادعای مالکیت بر نرم‌افزارها، کتابخانه‌ها، مدل‌ها، فونت‌ها، تصاویر، صداها، داده‌ها، علائم یا سایر آثار متعلق به اشخاص ثالث ندارد. حقوق آن موارد متعلق به صاحبانشان است و استفاده از آن‌ها تابع مجوز و شرایط مستقل مربوط به خودشان است.

## ۲. موارد ممنوع بدون اجازه کتبی

بدون مجوز کتبی قبلی از صاحب حق مربوط، هیچ شخصی مجاز نیست، در حدی که قانون اجازه می‌دهد:

- کد یا بخش‌های قابل‌توجهی از آثار اختصاصی پروژه را کپی، تکثیر یا بازنشر کند؛
- نسخه‌ای تغییر‌یافته، اقتباسی، مشتق‌شده، بازبسته‌بندی‌شده یا مبتنی بر پروژه ایجاد یا منتشر کند؛
- پروژه یا اجزای اختصاصی آن را بفروشد، اجاره دهد، sublicense کند یا به‌صورت تجاری عرضه کند؛
- فایل‌ها، مستندات، طراحی‌ها یا دارایی‌های اختصاصی را در پروژه یا محصول دیگری ادغام یا توزیع کند؛
- اعلان‌های حق نشر، انتساب پدیدآورنده یا اطلاعات مالکیت را حذف، مخدوش یا تغییر دهد؛
- خود را صاحب اثر یا پدیدآورنده بخش‌هایی معرفی کند که حقوق آن متعلق به دیگری است.

صرف دسترسی به مخزن، مشاهده، دانلود از طریق قابلیت‌های GitHub یا وجود امکان فنی Fork به معنی صدور مجوز مستقل برای استفاده، انتشار مجدد یا بهره‌برداری خارج از شرایط پلتفرم نیست. استفاده از GitHub همچنان تابع شرایط خدمات GitHub و مجوز محدودی است که برای میزبانی و نمایش محتوا به آن پلتفرم داده می‌شود.

## ۳. استثناها و حقوق غیرقابل‌سلب

هیچ بخشی از این سند قصد محدودکردن حقوقی را ندارد که طبق قانون قابل اعمال قابل اسقاط یا محدودکردن نیستند؛ از جمله استثناها و محدودیت‌های قانونی مربوط به استفاده منصفانه/منصفانه‌رفتار (در صورت کاربرد)، مهندسی معکوس مجاز در موارد قانونی، دسترس‌پذیری، یا حقوق مصرف‌کننده. تفسیر این موارد وابسته به حوزه قضایی و شرایط واقعی است.

## ۴. اجزای شخص ثالث و وابستگی‌ها

Project Kira ممکن است از کتابخانه‌های متن‌باز، مدل‌های هوش مصنوعی، سرویس‌ها، فونت‌ها، تصاویر، صداها یا ابزارهای متعلق به دیگران استفاده کند. هیچ‌یک از محدودیت‌های این سند جایگزین یا ناسخ مجوز آن اجزا نیست. پیش از استفاده یا توزیع هر وابستگی باید فایل مجوز و شرایط رسمی همان وابستگی بررسی شود.

در صورت تعارض میان این سند و مجوز معتبر یک جزء شخص ثالث، مجوز همان جزء فقط نسبت به همان جزء حاکم است؛ این موضوع به‌خودی‌خود برای سایر اجزای اختصاصی پروژه مجوز ایجاد نمی‌کند.

## ۵. نام، نشان و هویت پروژه

نام‌ها، نشان‌ها، لوگوها، شخصیت‌ها و عناصر هویتی مرتبط با Kira/Ai1، در حدی که متعلق به صاحب حق باشند و قانون حمایت کند، برای معرفی منبع پروژه استفاده می‌شوند. این سند ادعای ثبت علامت تجاری یا مالکیت بر نام‌ها و عناصر متعلق به اشخاص ثالث را مطرح نمی‌کند. استفاده‌ای که موجب القای وابستگی، تأیید یا حمایت رسمی شود مجاز نیست مگر با اجازه صاحب حق مربوط.

## ۶. درخواست مجوز

برای درخواست مجوز استفاده، بازتوزیع، اقتباس یا استفاده تجاری، ابتدا از طریق حساب GitHub زیر با نگه‌دارنده پروژه تماس بگیرید و دامنه استفاده، فایل‌های موردنظر، نوع توزیع، مدت و قلمرو جغرافیایی را توضیح دهید:

- GitHub: https://github.com/alizesta

تا زمان دریافت اجازه کتبی روشن، درخواست مجوز به معنی موافقت نیست و سکوت به منزله رضایت محسوب نمی‌شود.

## ۷. گزارش استفاده غیرمجاز

اگر تصور می‌کنید محتوای اختصاصی این پروژه بدون مجوز استفاده یا بازنشر شده است، نشانی دقیق محتوا، فایل‌ها یا commitهای مرتبط، مدرک مالکیت یا اختیار نمایندگی، و شرح استفاده مورد اعتراض را از طریق GitHub ارائه کنید. گزارش باید دقیق و با حسن نیت باشد. صاحب حقوق می‌تواند متناسب با قانون و شواهد، درخواست حذف محتوا، توقف استفاده یا سایر راهکارهای قانونی را بررسی کند.

## ۸. حفظ شواهد و مدیریت حقوق

برای پشتیبانی از ادعای حقوقی، صاحب پروژه باید نسخه‌های تاریخ‌دار، سوابق commit، فایل‌های منبع، قراردادهای واگذاری حقوق از پیمانکاران/همکاران، مجوز دارایی‌های ثالث و شواهد انتشار را نگهداری کند. درج این اطلاعیه به‌تنهایی مالکیت آثاری را که متعلق به شخص دیگری است منتقل نمی‌کند.

## ۹. قانون حاکم و تفسیر

قانون حاکم و مرجع صالح باید با توجه به محل اقامت و فعالیت صاحب حقوق، محل وقوع تخلف، قراردادهای مرتبط و قواعد تعارض قوانین تعیین شود. چون این اطلاعات در این مخزن احراز نشده‌اند، این سند قانون یا دادگاه خاصی را به‌صورت قطعی انتخاب نمی‌کند.
