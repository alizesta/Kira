# پشتیبانی آواتار سه‌بعدی VRM در Ai1

## وضعیت

Ai1 از یک backend اختیاری VRM در کنار backend دوبعدی PNG استفاده می‌کند. انتخاب مدل برای هر پروفایل شخصیت جداگانه ذخیره می‌شود. تا وقتی مدل VRM انتخاب نشده یا WebEngine نتواند آن را نمایش دهد، آواتار PNG قبلی بدون تغییر باقی می‌ماند.

## انتخاب مدل

در مسیر **Characters → آواتار سه‌بعدی (VRM)** فایل محلی با پسوند .vrm را انتخاب کن. Ai1 قبل از ثبت مسیر، ساختار GLB و افزونه VRM را بررسی می‌کند و نام، نسخه، اسکلت Humanoid، Expressionها، Spring Bone و metadata مجوز را نمایش می‌دهد.

مسیر در اطلاعات پروفایل کاراکتر ذخیره می‌شود؛ خود فایل:
- به پوشه نصب کپی نمی‌شود؛
- وارد Git یا ZIP انتشار نمی‌شود؛
- تغییر نام یا دست‌کاری نمی‌شود؛
- برای بارگذاری فقط از همان مسیر محلی خوانده می‌شود.

اگر فایل جابه‌جا یا حذف شود، آواتار PNG به‌عنوان fallback باقی می‌ماند.

## موتور نمایش

- Qt WebEngine درون پنجره دسکتاپ را میزبانی می‌کند.
- three.js نسخه 0.180.0 و @pixiv/three-vrm نسخه 3.5.5 برای خواندن VRM 1.0/0.x استفاده می‌شوند.
- نمایشگر فقط روی 127.0.0.1 یک HTTP server موقت باز می‌کند و فقط سه مسیر ثابت را ارائه می‌دهد: صفحه نمایشگر، کد viewer و فایل VRM انتخاب‌شده.
- فایل VRM به هیچ سرویس بیرونی آپلود نمی‌شود.
- نسخه فعلی کتابخانه‌های JavaScript را از jsDelivr می‌گیرد؛ بنابراین برای نمایش سه‌بعدی اتصال اینترنت لازم است. اگر CDN در دسترس نباشد یا WebGL/Qt WebEngine اجرا نشود، PNG جایگزین می‌شود.
- VRMUtils.rotateVRM0 برای جهت سازگار مدل‌های VRM 0.x استفاده می‌شود.
- vrm.update() به‌روزرسانی Spring Bone و Expressionها را اجرا می‌کند.

## اتصال انیمیشن

Backend سه‌بعدی از حالت جاری EmotionFaceAnimator استفاده می‌کند:
- blink / blinkLeft / blinkRight برای پلک‌زدن؛
- happy, sad, angry, surprised, relaxed در صورت وجود در مدل؛
- aa, ih, ou, ee, oh برای حرکت تقریبی دهان هنگام صحبت؛
- حرکت بسیار ملایم و procedural برای hips، spine، chest، neck و head؛
- چرخاندن مدل با کشیدن ماوس در نمای اصلی و جابه‌جایی پنجره Companion با کشیدن آن.

VRM حاوی اسکلت یا Expression به‌تنهایی انیمیشن آماده یا حرکت واقع‌گرایانه تضمین نمی‌کند. حرکت بدن فعلی procedural است؛ واردکردن فایل‌های motion/VRMA و نگاشت پیشرفته‌تر حالت‌های چهره کار بعدی است.

## مجوز و حریم خصوصی

Ai1 مقدارهای license metadata را فقط می‌خواند و نشان می‌دهد؛ آن‌ها را تغییر نمی‌دهد و از روی آن‌ها مالکیت یا اجازه‌ی استفاده را نتیجه‌گیری نمی‌کند. مسئولیت انتخاب و استفاده از مدلی که کاربر به آن دسترسی قانونی دارد با کاربر است. این طراحی عمداً مدل خصوصی را از بسته‌های انتشار جدا نگه می‌دارد.

## تست‌ها و محدودیت‌ها

tests/test_vrm_metadata.py ظرف GLB، تشخیص VRM 1.0، اسکلت، Expressionها، metadata مجوز و سازگاری پروفایل‌های قدیمی را می‌سنجد. آزمون واقعی WebGL/Qt WebEngine، سازگاری GPU و کیفیت نهایی Lip Sync به runtime ویندوز وابسته است؛ در صورت خطای رندر، backend PNG باقی می‌ماند.
