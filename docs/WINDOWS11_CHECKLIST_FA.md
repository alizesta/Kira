# مواردی که باید روی Windows 11 واقعی تست شوند

نصب: `install.bat` ← `start_kira.bat`. برای اجرای تست‌ها: `run_tests.bat`.

- [ ] برنامه بالا می‌آید و نوار نشانگر مدل پایین کنار فیلد پیام دیده می‌شود (حالت راست‌به‌چپ هم).
- [ ] تنظیمات 1.5.0/1.4.x قبلی خوانده می‌شود: کلیدها سر جایشان، ترتیب Routeها همان ترتیب قبلی (کلیدها با DPAPI باز می‌شوند).
- [ ] Drag & Drop با ماوس در فهرست Route کار می‌کند و بعد از ری‌استارت حفظ می‌شود.
- [ ] کلید واقعی Groq: «تست اتصال» ✓؛ چت Streaming متن را کم‌کم نشان می‌دهد؛ دکمه‌ی توقف کار می‌کند.
- [ ] کلید اشتباه ← خطای ۴۰۱ و Failover؛ قطع اینترنت (یا VPN) ← Failover به Ollama.
- [ ] ۴۲۹ واقعی (چندبار پشت‌سرهم) ← Cooldown و رفتن به Route بعدی.
- [ ] Ollama واقعی: `qwen3.5:4b` Streaming می‌دهد؛ «یافتن مدل‌های Ollama»؛ Benchmark سهم GPU (RX 6600 XT) را نشان می‌دهد.
- [ ] Ollama را وسط پاسخ ببند (End Task): متن ناقص حفظ و بدون تکرار؛ خطا خوانا.
- [ ] هنگام بازی: مدل بعد از Keep-alive آزاد می‌شود و FPS بازی افت دائمی ندارد.
- [ ] فارسی راست‌به‌چپ در حباب در حال Streaming درست چیده می‌شود.
- [ ] چهره/لب‌خوانی/شخصیت روی دسکتاپ/صدا/میکروفون مثل قبل کار می‌کنند (کدشان دست‌نخورده است اما روی ویندوز تست مجدد لازم است).
- [ ] چند مکالمه‌ی پشت‌سرهم (۲۰+) و دیدن Task Manager برای رشد رم.
- [ ] `logs/provider_telemetry.jsonl` را باز کن: نه کلید دارد نه متن مکالمه.
- [ ] Provider سفارشی (مثلاً LM Studio روی `localhost:1234`).
