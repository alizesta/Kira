# چک‌لیست پذیرش روی Windows 11 واقعی

این فهرست برای آزمون دستی روی دستگاه Windows است. وجود تست واحد یا موفقیت نصب به‌تنهایی پذیرش GUI، صدا، بلوتوث یا سخت‌افزار را ثابت نمی‌کند.

## نصب و راه‌اندازی
- [ ] install.bat با Python 3.11 یا 3.12 اجرا می‌شود و مسیر داده پایدار را ذخیره می‌کند.
- [ ] مدل Shenava INT8 و صدای فارسی Piper آماده می‌شوند؛ اگر نصب صوتی شکست خورد، هشدار قابل‌فهم دیده می‌شود.
- [ ] بررسی شود که Ollama و مدل چت به‌صورت خودکار توسط install.bat نصب نمی‌شوند.
- [ ] برای مدل محلی پین‌شده، scripts/setup_local_chat_model.py اجرا شود؛ SHA-256 مدل بررسی و smoke test موفق شود.
- [ ] start_kira.bat و start_kira.vbs اجرا شوند؛ لاگ launcher در مسیر داده قابل مشاهده باشد.
- [ ] برنامه پس از restart تنظیمات، Providerها، Routeها و تاریخچه را حفظ کند.

## Chat و Providerها
- [ ] Provider معتبر و نامعتبر؛ تست اتصال، خطاهای 401/429 و Failover.
- [ ] Ollama واقعی: مدل نصب‌شده در فهرست Routeها ظاهر شود، Streaming کار کند و قطع Ollama خطای خوانا بدهد.
- [ ] مدل محلی در صورت انتخاب، Context و Keep-alive را رعایت کند.
- [ ] پیوست تصویر، فایل متنی، DOCX و PDF با محدودیت اندازه/نوع درست پردازش شوند.
- [ ] چند Session/Character مستقل باشند و بستن Session داده پایدار را حذف نکند.

## Voice و رسانه
- [ ] Gemini Live با کلید Google معتبر متصل شود؛ به کاربر روشن باشد که صدای میکروفن در این حالت به Google ارسال می‌شود.
- [ ] انتخاب حالت محلی، Shenava را برای STT و Piper را برای فارسی اجرا کند.
- [ ] قطع Gemini Live با fallback روشن به مسیر محلی منتقل شود؛ با fallback خاموش خطای روشن نمایش داده شود.
- [ ] KittenTTS فقط جمله‌های انگلیسی را بخواند و جمله‌های فارسی همچنان با Piper پخش شوند.
- [ ] میکروفن، gain، حساسیت، هدفون/بلندگو، Stop و barge-in بررسی شوند.
- [ ] QAudioSink، WAV PCM، تغییر دستگاه خروجی و صدای جمله‌به‌جمله بررسی شوند.

## ابزارها و ایمنی
- [ ] PathPolicy پوشه‌های مجاز را محدود و فایل‌های حساس را رد کند.
- [ ] عملیات PROTECTED بدون تأیید صریح اجرا نشوند؛ تأیید به همان عملیات و آرگومان‌ها محدود باشد.
- [ ] کنترل پنجره، تایپ، کلیدهای مجاز، Clipboard و UI Automation فقط روی پنجره هدف و مطابق سیاست اجرا شوند.
- [ ] بلوتوث و کنترل صدای سیستم نتیجه واقعی را پس از تغییر بررسی کنند.
- [ ] Game Mode: Competitive Safe ابزارهای کنترلی را fail-closed مسدود کند؛ تشخیص بازی پروفایل را خودکار تغییر ندهد.
- [ ] WebIntel، URL guard، محدودیت redirect/size/time و ادامه/توقف تحقیق بررسی شوند.
- [ ] MCP server نامعتبر یا قطع‌شده مجوز اضافه نگیرد و خطای آن ایزوله بماند.
