# انتقال محل مدل‌های Ollama به درایو A

مدل‌های چت Ollama مستقل از کش داخلی Kira ذخیره می‌شوند. برای نگه‌داشتن آن‌ها در کنار داده‌های Kira:

1. مطمئن شو درایو A در دسترس است.
2. Ollama را از آیکون System Tray کاملاً ببند.
3. فایل `configure_ollama_storage.bat` را از پوشهٔ اصلی Kira اجرا کن و انتقال را تأیید کن.
4. اسکریپت، مدل‌های موجود را از مسیر فعلی به این مسیر **کپی** می‌کند:

```text
A:\Project KIRA\Kira Attachments\ollama\models
```

5. متغیر کاربری ویندوز `OLLAMA_MODELS` را روی مسیر بالا تنظیم می‌کند.
6. Ollama را دوباره از Start Menu اجرا کن و با `ollama list` دیده‌شدن مدل‌ها را بررسی کن.

**فایل‌های مبدا حذف نمی‌شوند.** انتقال با کپی انجام می‌شود تا در صورت بروز خطا مدل‌های قبلی محفوظ بمانند. بعد از اطمینان از اینکه Ollama مدل‌ها را از مسیر جدید می‌خواند، می‌توانی پوشهٔ قدیمی را خودت پاک کنی.

اگر نسخهٔ Desktop Ollama تنظیم جداگانه‌ای به نام **Model location** دارد، آن را هم روی همین مسیر قرار بده؛ این مقدار باید با `OLLAMA_MODELS` یکسان باشد. بعد از تغییر مسیر حتماً Ollama را کامل ببند و دوباره اجرا کن.

این اسکریپت برای مسیر پیش‌فرض `%USERPROFILE%\.ollama\models` و مسیری که متغیر فعلی `OLLAMA_MODELS` نشان می‌دهد کار می‌کند. تنظیمات و کش Kira، Qwen، Piper، PyTorch و Hugging Face جداگانه از طریق `KIRA_DATA_DIR` در همان پوشهٔ A ذخیره می‌شوند.
