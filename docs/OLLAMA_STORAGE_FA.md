# محل ذخیره مدل‌های Ollama

مدل‌های Ollama مستقل از پایگاه داده و cache داخلی Kira ذخیره می‌شوند. پوشه داده Kira از طریق KIRA_DATA_DIR مدیریت می‌شود؛ محل مدل‌های Ollama را خود Ollama و متغیر محیطی OLLAMA_MODELS کنترل می‌کند.

## وضعیت ابزار انتقال در مخزن فعلی

راهنمای قدیمی به فایل configure_ollama_storage.bat اشاره می‌کرد، اما این فایل در نسخه فعلی مخزن وجود ندارد. بنابراین آن دستور را اجرا نکن؛ در حال حاضر ابزار انتقال خودکار مدل‌های Ollama در این پروژه ارائه نشده است.

## انتقال دستی مدل‌ها

اگر قصد انتقال مدل‌های موجود را داری:
1. Ollama را از System Tray کاملاً ببند و مطمئن شو سرویس آن متوقف شده است.
2. پوشه فعلی مدل‌ها را پیدا کن؛ معمولاً در مسیر کاربری Ollama قرار دارد یا از مقدار فعلی OLLAMA_MODELS مشخص می‌شود.
3. پوشه models را به مقصد جدید **کپی** کن؛ فایل‌های مبدا را تا پایان بررسی حذف نکن.
4. متغیر محیطی کاربر OLLAMA_MODELS را روی مسیر جدید پوشه models قرار بده.
5. Ollama را دوباره اجرا کن و با دستور ollama list دیده‌شدن مدل‌ها را بررسی کن.
6. یک مدل را واقعاً اجرا کن و مطمئن شو فضای ذخیره‌سازی جدید استفاده می‌شود؛ فقط بعد از تأیید کامل می‌توانی درباره پاک‌کردن نسخه قبلی تصمیم بگیری.

تغییر مسیر ذخیره‌سازی را با راهنمای رسمی نسخه نصب‌شده Ollama تطبیق بده؛ تنظیمات Desktop و متغیر محیطی باید با هم سازگار باشند.

## تفکیک داده‌ها

- KIRA_DATA_DIR: تنظیمات، تاریخچه گفتگو، فایل‌های داده و cacheهای برنامه.
- OLLAMA_MODELS: وزن مدل‌های چت Ollama.
- Hugging Face cache: مدل‌های Shenava، Piper و سایر وزن‌هایی که در مسیر cache برنامه پیکربندی شده‌اند.

نصب‌کننده فعلی Kira مدل چت Ollama را به‌طور خودکار نصب نمی‌کند. برای مدل محلی پین‌شده Kira، از راهنمای docs/ADD_PROVIDER_AND_MODEL_FA.md استفاده کن.
