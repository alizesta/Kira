# راهنمای کاربر Kira

## ۱. نصب و اجرا

۱. فایل **install.bat** را روی رایانهٔ هدف با Windows 11 اجرا کنید.
۲. هنگامی که نصب‌کننده درخواست می‌کند، پوشهٔ داده‌ها را انتخاب کنید. مسیر انتخاب‌شده در به‌روزرسانی‌های بعدی نیز استفاده می‌شود.
۳. اجازه دهید نصب‌کننده وابستگی‌های برنامه و مؤلفه‌های محلی پیکربندی‌شده را آماده کند.
۴. برنامه را با **start_kira.bat** اجرا کنید.

برای به‌روزرسانی از **update_kira.bat** استفاده کنید. در صورت شکست نصب وابستگی یا تست متمرکز، خروجی به‌روزرسانی را بررسی کنید.

## ۲. پیکربندی مسیر هوش مصنوعی

۱. تنظیمات Route را باز کنید.
۲. **Add API** را انتخاب و کلید API یکی از Providerهای پشتیبانی‌شده را وارد کنید.
۳. اجازه دهید Kira کلید را اعتبارسنجی و فهرست مدل‌های Provider را دریافت کند.
۴. یک Route اضافه یا فعال کنید و اولویت و مدل آن را انتخاب کنید.
۵. تنظیمات را ذخیره کنید.

صرف دیده‌شدن یک Provider در برنامه به معنی فعال‌بودن آن نیست. کلیدهای API را محرمانه نگه دارید و فقط در تنظیمات Provider برنامه وارد کنید. راهنماها: [مدیر API](API_MANAGER_FA.md) و [مدیر مسیر](ROUTE_MANAGER_GUIDE_FA.md).

## ۳. انتخاب زبان رابط

زبان پیش‌فرض رابط انگلیسی است. تنظیمات عمومی/Preferences را باز کنید، در فهرست Interface language گزینهٔ **فارسی** را انتخاب و تنظیمات را ذخیره کنید. جهت رابط به راست‌به‌چپ تغییر می‌کند. برای بازگشت به انگلیسی، گزینهٔ **English** را انتخاب کنید.

زبان رابط به‌صورت خودکار زبان تشخیص گفتار، تولید گفتار یا زبان پیام‌ها را تغییر نمی‌دهد؛ این موارد مستقل هستند.

## ۴. چت و گفتگوها

- برای گفتگوی معمولی، پرسش‌ها و کارهای پشتیبانی‌شده از صفحهٔ Chat استفاده کنید.
- تاریخچهٔ گفتگو برای هر پروفایل شخصیت به‌صورت مستقل نگهداری می‌شود.
- با گزینهٔ گفتگوی جدید می‌توانید مکالمه‌ای مستقل بسازید، بدون اینکه گفتگوی قبلی حذف شود.
- برای مدیریت داده‌های گفتگو از کنترل‌های تاریخچه و حافظه در Preferences استفاده کنید.
- پروفایل‌های شخصیت از سرویس‌های مشترک برنامه استفاده می‌کنند، اما وضعیت گفتگو و نمایش مستقل خود را دارند.

## ۵. جست‌وجو و تحقیق

برای جست‌وجوی سریع از کنترل جست‌وجوی وب کنار کادر پیام استفاده کنید. برای تهیهٔ گزارش چندمنبعی، از Kira بخواهید دربارهٔ موضوعی تحقیق کند یا پیوندی را بخواند. تحقیق چندمنبعی با جست‌وجوی سریع متفاوت است: منابع مستقل را می‌خواند، شواهدشان را مقایسه می‌کند و ارجاع‌ها، سطح اطمینان، تناقض‌ها و کمبود شواهد را گزارش می‌دهد.

تحقیق قابل توقف و ادامه است. گزارش تحقیق تضمین نمی‌کند که تمام ادعاهای وب درست باشند؛ منابع و توضیحات اطمینان را بررسی کنید.

## ۶. پیوست فایل و تصویر

از کنترل پیوست، کشیدن فایل به داخل چت یا در صورت پشتیبانی، چسباندن تصویر از Clipboard استفاده کنید. قالب‌های متنی و سندی تابع فهرست خواننده‌های پشتیبانی‌شدهٔ برنامه هستند. تفسیر تصویر به یک Route مدل سازگار با بینایی نیاز دارد.

اطلاعات ورود، کلیدهای خصوصی یا داده‌های شخصی نامرتبط را پیوست نکنید. دسترسی به فایل تابع قواعد پردازش محلی و مجوزهای برنامه است.

## ۷. صدا

Kira دارای حالت مکالمهٔ Gemini Live و مؤلفه‌های پردازش صوتی محلی است.

- تشخیص گفتار محلی از موتور ASR آفلاین انتخاب‌شده و fallback محلی پشتیبانی‌شده استفاده می‌کند.
- تولید گفتار محلی با Piper انجام می‌شود.
- Gemini Live یک حالت مستقل با اتصال ابری است و به Provider و مدل پیکربندی‌شده نیاز دارد.
- ورودی میکروفن و خروجی بلندگو را می‌توان در تنظیمات صدا انتخاب کرد.

موتور صدا، زبان تشخیص گفتار و زبان رابط مستقل هستند. برای جزئیات: [صدای محلی](LOCAL_VOICE_FA.md)، [مسیریابی صدا](VOICE_ROUTE_FA.md) و [Gemini Live](GEMINI_LIVE_FA.md).

## ۸. Eye Mode و ابزارهای دسکتاپ

Eye Mode تا زمانی که کاربر آن را فعال نکند خاموش است. این قابلیت با رعایت بررسی پنجرهٔ پیش‌زمینه و حریم خصوصی، مانیتور انتخاب‌شده را نمونه‌برداری و زمینه‌ای محدود نگهداری می‌کند. Eye Mode ضبط مداوم ویدئوی تمام‌فریم نیست.

سیستم ابزارها فقط قابلیت‌های پشتیبانی‌شدهٔ آگاهی از رایانه و عملیات فایل را ارائه می‌دهد. عملیات حساس به تأیید صریح نیاز دارند؛ این سیستم یک Shell نامحدود نیست.

## ۹. Kira Code

برای درخواست کدنویسی چندفایلی، تغییر موردنظر را در چت معمولی توضیح دهید. پس از تشخیص وظیفهٔ پروژه، Agent در صورت نیاز پوشهٔ پروژه را می‌پرسد، فایل‌های مرتبط را بررسی می‌کند، یک برنامهٔ محدود پیشنهاد و روی نسخهٔ کاری اجرا می‌کند، بررسی‌های پشتیبانی‌شده را انجام می‌دهد، Diff را بازبینی و خروجی را بسته‌بندی می‌کند.

اجراکنندهٔ دستورهای Agent به بررسی‌های توسعهٔ پشتیبانی‌شده محدود است. دستورهای میزبان و عملیات مخرب به تأیید نیاز دارند. این فرایند جایگزین Sandbox امنیتیِ جداگانه نیست.

## ۱۰. عیب‌یابی

- **هیچ مدلی در دسترس نیست:** Route فعال، Provider روشن، اعتبارسنجی کلید API، شناسهٔ مدل و اتصال Provider را بررسی کنید.
- **چت محلی در دسترس نیست:** مطمئن شوید Ollama در حال اجرا است و مدل پیکربندی‌شده نصب شده است.
- **صدا کار نمی‌کند:** موتور انتخاب‌شده، پیکربندی Provider برای Gemini Live، مجوز میکروفن، دستگاه خروجی و در دسترس‌بودن مدل محلی را بررسی کنید.
- **زبان رابط تغییر نکرد:** زبان را دوباره انتخاب، تنظیمات را ذخیره و صفحهٔ مربوط را باز کنید. زبان ذخیره‌شدهٔ قبلی بر پیش‌فرض نصب‌های جدید اولویت دارد.
- **قابلیت دسکتاپ در دسترس نیست:** فعال‌بودن قابلیت، مجازبودن پنجرهٔ هدف و وجود API یا سخت‌افزار لازم Windows را بررسی کنید.

## ۱۱. اجرای تست‌ها

از ریشهٔ مخزن دستور زیر را اجرا کنید:

```text
python -m unittest discover -s tests -t .
```

در Windows فایل **run_tests.bat** نیز موجود است. رفتارهای وابسته به سخت‌افزار و رابط تعاملی باید روی رایانهٔ Windows آزمایش شوند.
