# آگاهی از کامپیوتر و سامانه ابزارهای Kira

این راهنما وضعیت فعلی Tool System را توضیح می‌دهد؛ راهنمای مرحلهٔ اولیه دیگر فهرست کامل قابلیت‌ها نیست. برای قواعد اجرایی و سطوح امنیتی به [راهنمای System Access](SYSTEM_ACCESS_FA.md) مراجعه کن.

## معماری اجرا

1. ToolAgent و پروتکل متنی تشخیص می‌دهند آیا پیام فعلی کاربر به ابزار نیاز دارد. در گفتگوی عادی، کاتالوگ ابزارهای نامرتبط به مدل داده نمی‌شود.
2. مدل فقط نام ابزار و آرگومان‌های ساخت‌یافته را پیشنهاد می‌کند؛ خودش ابزار را اجرا یا مجوز صادر نمی‌کند.
3. ToolRegistry آرگومان‌ها را اعتبارسنجی و اجرا را به System Access Manager می‌سپارد.
4. نتیجه یا خطای واقعی handler به مدل برمی‌گردد. نتیجهٔ ابزار به‌تنهایی موفقیت نهایی وظیفه را ثابت نمی‌کند.
5. برای درخواست‌های چندمرحله‌ای، Autonomous Agent می‌تواند مراحل را برنامه‌ریزی کند؛ هر مرحله همچنان از همان Registry و همان سیاست دسترسی عبور می‌کند.

## گروه‌های ابزار

### اطلاعات سیستم و فایل‌های مجاز
- ساعت/تاریخ، مشخصات سیستم، CPU/RAM/GPU/باتری، دیسک‌ها، شبکه و برنامه‌های باز.
- پیدا کردن برنامه، فهرست پنجره فعال و خواندن اطلاعات فایل.
- جست‌وجو، فهرست‌کردن، بررسی مشخصات و خواندن فایل‌های پشتیبانی‌شده (متن، کد، CSV، JSON، DOCX و PDF).

### کنترل Windows
ماژول‌های ثبت‌شده در حال حاضر:
- **Apps:** یافتن و بازکردن برنامه‌های Start Menu، برنامه‌های نصب‌شده، Store و بازی‌های Steam.
- **Bluetooth:** خواندن وضعیت و روشن/خاموش‌کردن با درخواست صریح کاربر.
- **Audio:** خواندن و تغییر سطح صدای سیستم/برنامه‌ها و انتخاب دستگاه‌های صوتی.
- **Desktop:** فهرست و تمرکز پنجره‌ها، تغییر وضعیت یا بستن پنجره، تایپ و کلیدهای مجاز، تعامل محدود با کنترل‌های UI و Clipboard.

جزئیات: [اجرای برنامه‌ها](APP_LAUNCH_FA.md)، [کنترل ویندوز](WINDOWS_CONTROL_FA.md) و [تعامل دسکتاپ](DESKTOP_FA.md).

### مدیریت فایل
علاوه بر خواندن فایل، عامل فایل عملیات ساخت پوشه/فایل، افزودن متن، کپی، تغییرنام، نوشتن، مرتب‌سازی، عملیات گروهی و Undo را در محدوده PathPolicy ارائه می‌کند. عملیات حساس مانند حذف، جابه‌جایی یا بازنویسی محافظت‌شده به تأیید کاربر نیاز دارند. جزئیات: [عامل فایل](FILE_AGENT_FA.md).

### وب، تحقیق و MCP
- ابزارهای Web Search و WebIntel برای جست‌وجو، خواندن صفحه و تحقیق چندمنبعی؛ دریافت وب دارای محدودیت‌های URL، SSRF، حجم، زمان و Redirect است.
- سرورهای MCP فقط از فایل تنظیمات کاربر ثبت می‌شوند. خروجی سرور دادهٔ غیرقابل‌اعتماد است و annotation سرور مجوز را تعیین نمی‌کند.
- ایجنت مستقل از طریق ابزارهای agent_* فقط با درخواست کاربر و کنترل‌های تأیید/وضعیت قابل استفاده است.

راهنماها: [تحقیق وب](WEB_RESEARCH_FA.md) و [MCP و ایجنت‌ها](MCP_AGENTS_FA.md).

## سطوح دسترسی و تأیید

ToolRegistry سطح سازگاری READ/ACTION/SENSITIVE دارد؛ سیاست مرکزی System Access آن‌ها را به این مجوزها نگاشت می‌کند:

| مجوز | معنی | شرط |
|---|---|---|
| READ | فقط خواندن | بدون تأیید |
| CONTROL | کنترل برگشت‌پذیر Windows/برنامه | درخواست صریح در پیام فعلی یا opt-out مستند |
| FILE | عملیات غیرمخرب فایل | PathPolicy و درخواست صریح |
| ELEVATED | عملیات نیازمند Administrator | تأیید صریح؛ در این نسخه قابلیت عمومی UAC ثبت نشده است |
| PROTECTED | عملیات حساس/مخرب | تأیید صریح برای همان ابزار و همان آرگومان‌ها |

- تأیید به عملیات ذخیره‌شده متصل، یک‌بارمصرف و دارای مهلت محدود است. پیام جدیدی که کار دیگری را درخواست کند، تأیید قبلی محسوب نمی‌شود.
- محتوای بیرونی خوانده‌شده از وب، فایل، MCP یا ایجنت می‌تواند turn را tainted کند؛ بعضی عملیات بعدی برای جلوگیری از اجرای دستور پنهان، تأیید اضافه می‌خواهند.
- اگر ابزار شکست بخورد، مدل همان خطا را می‌بیند و نباید موفقیت ادعا کند.
- PowerShell آزاد، shell عمومی یا اجرای کد دلخواه از متن مدل وجود ندارد. فقط اسکریپت ثابت و محدود تعریف‌شده در کد ممکن است از مسیر winrunner اجرا شود.

## محدوده فایل و حریم خصوصی

- مسیرهای پیش‌فرض: Desktop، Documents، Downloads، Pictures، Videos و Music کاربر Windows؛ مسیرهای اضافه فقط با تنظیم خود کاربر.
- مسیر دادهٔ Kira، AppData، فایل‌های کلید/رمز و مسیرهای سیستمی حساس مسدود می‌شوند. مسیر نهایی resolve می‌شود تا symlink یا .. نتواند از محدوده خارج شود.
- محتوای فایلی که از Kira می‌خواهی بخواند به مدل فعال فرستاده می‌شود. اگر Route چت ابری باشد، متن استخراج‌شده نیز به همان Provider ارسال می‌شود؛ برای محتوای خصوصی از Route محلی استفاده کن.
- ابزارهای خواندن/کنترل سیستم به‌خودی‌خود به شخصیت Kira، Mika یا Ren مجوز اضافه نمی‌دهند؛ همه از سیاست مشترک استفاده می‌کنند.

## تنظیمات اصلی

| کلید | پیش‌فرض | معنی |
|---|---|---|
| tools_mode | auto | auto فقط برای درخواست‌های مرتبط با PC؛ always ابزارها را در دسترس نگه می‌دارد؛ off ابزارهای هوشمند را خاموش می‌کند |
| tools_allowed_paths | [] | پوشه‌های اضافی مجاز |
| tools_max_rounds | 4 | سقف دورهای ابزار در یک پاسخ (۱ تا ۶) |
| agent_planning | auto | برنامه‌ریزی چندمرحله‌ای خودکار برای وظایف مرتبط با PC |
| agent_max_steps | 8 | سقف مراحل برنامه‌ریزی‌شده (۲ تا ۱۵) |
| mcp_mode | auto | استفاده از kira_mcp.json در صورت وجود؛ off برای خاموش‌کردن MCP |

## محدودیت‌های پذیرش

وجود handler و تست قرارداد به معنی آزمون روی Windows واقعی نیست. کنترل پنجره، UI Automation، Clipboard، بلوتوث، دستگاه‌های صوتی و اجرای برنامه‌ها باید روی نسخه واقعی Windows و با برنامه/سخت‌افزار هدف بررسی شوند.
