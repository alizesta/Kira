# تنظیمات صدا و Route

## ۱) ورودی و خروجی گفتار

تمام تشخیص گفتار و تولید گفتار فقط با موتورهای محلی انجام می‌شود:

- **ورودی/STT:** ابتدا Qwen3-ASR محلی؛ در صورت آماده‌نبودن یا خروجی خالی، faster-whisper محلی.
- **خروجی/TTS:** Piper محلی و فایل WAV تولیدشده روی همان سیستم.
- **میکروفن:** ضبط با sounddevice و دستگاه ورودی انتخاب‌شده.
- **بلندگو/هدفون:** پخش WAV محلی از دستگاه خروجی انتخاب‌شده.
- سرعت گفتار، بلندی خروجی، بلندی میکروفن و حساسیت ورودی مستقل‌اند.

هیچ مسیر Edge TTS، Windows SAPI، Google Speech Recognition یا Cloud Voice برای صدا وجود ندارد. اگر موتور محلی آماده نباشد، برنامه خطا نشان می‌دهد و به سرویس آنلاین سوییچ نمی‌کند.

## ۲) Route فقط برای مدل‌های چت است

Route Manager برای انتخاب مدل گفت‌وگو استفاده می‌شود:
- مدل‌های محلی Ollama
- Providerهای API چت که کاربر اضافه کرده است

افزودن یا اعتبارسنجی کلید API فقط قابلیت چت را بررسی می‌کند؛ هیچ درخواست آزمایشی STT/TTS ارسال نمی‌شود. فعال‌بودن Provider ابری برای چت، مسیر صوتی را تغییر نمی‌دهد.

## ۳) جداسازی اجزای برنامه

- موتورهای صوتی فقط گفتار را به متن یا متن را به WAV تبدیل می‌کنند.
- Router چت فقط مدل تولید پاسخ را انتخاب می‌کند.
- حافظه و شخصیت مستقل از موتور STT/TTS باقی می‌مانند.
- مدل‌های صوتی می‌توانند یک‌بار بارگذاری شوند و برای پیام‌های بعدی در حافظه بمانند.
