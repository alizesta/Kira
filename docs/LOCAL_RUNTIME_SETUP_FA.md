# راه‌اندازی مدل‌های محلی

نصب Kira سه وضعیت مستقل دارد: خود برنامه و وابستگی‌های Python؛ موتور اختیاری Ollama؛ و وزن مدل‌ها. نصب موتور فقط با اجازهٔ کاربر انجام می‌شود. دانلود مدل نیز فقط پس از واردکردن شناسهٔ دقیق و اعلام اندازهٔ Registry، فضای دیسک و ارزیابی سخت‌افزار شروع می‌شود.

برای نصب، تعمیر یا ادامهٔ دانلود ناقص:

~~~powershell
.venv\Scripts\python.exe -m kira.setup_manager --interactive
~~~

برای بررسی فقط‌خواندنی:

~~~powershell
.venv\Scripts\python.exe -m kira.setup_manager --status
~~~

گزارش، فایل اجرایی Ollama، اتصال سرور، نسخه، مدل‌های نصب‌شده، مدل انتخاب‌شده در تنظیمات و نتیجهٔ اجرای واقعی همان مدل را جداگانه نشان می‌دهد. نصب‌بودن مدل به معنی انتخاب‌شدن آن نیست و مدل تنظیم‌شده نیز تا وقتی مستقل اجرا نشود آماده محسوب نمی‌شود.

پیش از Pull، اندازهٔ لایه‌ها از Manifest رسمی Ollama خوانده می‌شود؛ ۱۰٪ فضای اضافه برای فراداده و بازیابی رزرو و فضای آزاد درایو مدل‌ها بررسی می‌شود. در کمبود فضا دانلود شروع نمی‌شود و اندازه‌ها از جدول ثابت حدس زده نمی‌شوند. RAM از Windows و VRAM انویدیا در صورت وجود nvidia-smi خوانده می‌شود. ارزیابی سخت‌افزار تقریبی است و سرعت را تضمین نمی‌کند.

API دانلود Ollama لایه‌های ناقص را نگه می‌دارد و Pull مجدد همان مدل می‌تواند ادامه پیدا کند. قطع دانلود تنظیم Route را تغییر نمی‌دهد. پس از دانلود موفق، برای انتخاب مدل به‌عنوان مدل محلی چت تأیید جداگانه گرفته می‌شود. مدل‌های قبلی حذف و Cache پاک نمی‌شود.

اگر winget در دسترس نبود، Ollama را با نصب‌کنندهٔ رسمی Windows نصب و سرور را اجرا کن؛ سپس Setup تعاملی را دوباره اجرا کن.
