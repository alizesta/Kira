# مغز چندمرحله‌ای (Surface / Deep / Reflection / Memory)

کد: `kira/brain.py`. صدای Kira همان یکی است (شخصیت + Active Mode + حافظه)؛ این ماژول فقط تصمیم می‌گیرد هر پیام چقدر پردازش لازم دارد.

## نقش‌ها
- **surface**: همان درخواست عادی قبلی؛ برای گپ و سؤال ساده. هیچ درخواست اضافه‌ای نمی‌سازد و پرامپت بدون تغییر می‌ماند.
- **deep**: همان یک درخواست، برای پیام‌های سنگین (برنامه چندمرحله‌ای، تسک ناتمام، تحلیل، پیام بلند، کد، فایل ضمیمه در حالت کار). می‌تواند مسیر (route) جدا داشته باشد و یک جمله‌ی کوتاه به پرامپت اضافه می‌شود. روی مدل محلی با `num_ctx ≤ 4096` (مثل Qwen 3.5 4B) هیچ چیزی اضافه نمی‌شود.
- **reflection**: بعد از پاسخ. قواعد رایگان: ادعای انجام کار بدون ابزار موفق، پنهان کردن خطای ابزار، نام اشتباه. نتیجه فقط یک «یادداشت» برای نوبت بعد است؛ پاسخ نمایش‌داده‌شده هرگز بازنویسی نمی‌شود و درخواستی دوباره ارسال نمی‌شود (حلقه ندارد). حالت `model` اختیاری است.
- **memory**: نوشتن واقعیت‌ها در پس‌زمینه (پیش‌فرض خاموش). هر واقعیت باید نقل‌قول کاربر باشد و در کد تأیید می‌شود.

## تنظیمات (`settings.json`)
| کلید | مقدار پیش‌فرض | معنی |
|---|---|---|
| `brain_mode` | `auto` | `surface_only` = هرگز deep؛ `off` = ماژول کاری نمی‌کند |
| `brain_reflection` | `rules` | `model` = علاوه بر قواعد، یک تماس پس‌زمینه روی نوبت deep؛ `off` |
| `brain_memory_writer` | `off` | `idle` = نویسنده‌ی حافظه در پس‌زمینه |
| `role_routes` | همه `auto` | شناسه‌ی route برای هر نقش؛ اگر قابل‌استفاده نباشد ترتیب عادی ادامه می‌یابد |

## ایمنی
- تصمیم‌گیری کدِ قطعی است، بدون تماس با مدل.
- تماس‌های پس‌زمینه روی Router دومی با قفل جداگانه اجرا می‌شوند؛ پیام بعدی کاربر را مسدود نمی‌کنند؛ سقف زمانی/ساعتی و backoff دارند.
- متن ارسالی به مدل پس‌زمینه از `redact_secrets` می‌گذرد؛ کلیدهای API هرگز وارد پرامپت نمی‌شوند.
- یادداشت (hint) تک‌بار مصرف است، کوتاه (۲۲۰ نویسه)، پاک‌سازی‌شده و با انقضا (۱ ساعت یا ۲ نوبت).
- حالت (state) در `kira_brain_state.json` ذخیره می‌شود، نه در هیچ ارائه‌دهنده؛ تغییر provider چیزی را از بین نمی‌برد.
- هر خطا = مسیر قدیمی. «پاک کردن گفتگو» یادداشت را هم پاک می‌کند.
- `brain.budget_check` قلاب برای T4 (محدودیت هزینه) است.

## تله‌متری
`logs/brain_telemetry.jsonl`: فقط metadata (مرحله، دلایل، نام قاعده)، بدون متن پیام.
