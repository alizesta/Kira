# قراردادهای مشترک Kira

این پوشه مرجع رفتار و API مشترک بین کلاینت Windows و Android است.

## مدل محصول

Kira یک محصول است با دو کلاینت بومی و یک هسته‌ی مشترک:

- **Kira Core Server:** مغز، شخصیت‌ها، Route، تنظیمات حساب، تاریخچه، حافظه و Sync
- **Windows Client:** رابط PySide6 و Adapterهای ویندوز
- **Android Client:** رابط Jetpack Compose و Adapterهای اندروید

نصب مستقل به معنی استقلال از داده و مغز نیست. هر دو کلاینت به یک حساب و یک Kira Core متصل می‌شوند.

## قراردادها

- feature-parity.json: وضعیت قابلیت‌ها و اصل هم‌ارزی
- kira-core-api-v1.yaml: قرارداد HTTP API برای احراز هویت، چت، Route، تنظیمات، حافظه و Sync

## داده‌ی حساب و داده‌ی دستگاه

اطلاعات مشترک در سرور و زیر شناسه‌ی حساب نگهداری می‌شود: تنظیمات عمومی، Providerهای Cloud، تاریخچه و حافظه. تنظیمات وابسته به سخت‌افزار، مجوزها، مدل محلی و ابزارهای سیستم‌عامل در فضای دستگاه باقی می‌ماند.

کلیدهای Provider نباید از API خواندنی برگردانده شوند. سرور آن‌ها را رمزنگاری‌شده نگه می‌دارد و درخواست‌های Cloud را از طرف حساب اجرا می‌کند.

## حساب و ورود

روش ورود از شناسه‌ی داخلی حساب جداست. نسخه‌ی اول از ایمیل/رمز عبور استفاده می‌کند. Google Sign-In بعداً به همان Account ID لینک می‌شود و نباید حساب، حافظه یا تاریخچه‌ی جدا بسازد.

## هم‌ارزی پلتفرمی

کد UI و APIهای سیستم‌عامل بین دو پلتفرم مشترک نیستند. قرارداد داده، نتیجه‌ی قابل مشاهده، قوانین امنیت و منطق اصلی مشترک‌اند. Windows Game Mode و Android AI Assistant دو Adapter برای یک قابلیت هستند.
