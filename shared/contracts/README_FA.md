# قرارداد قابلیت‌های مشترک

این پوشه مرجع هم‌ارزی قابلیت‌های Kira در ویندوز و اندروید است.

## چرا قرارداد مشترک؟

نسخه‌ی ویندوز Python/PySide6 است و نسخه‌ی Android با Kotlin و APIهای Native ساخته می‌شود. به همین دلیل، انتقال مستقیم کد رابط کاربری یا سرویس‌های سیستم‌عامل ممکن نیست. در عوض:

- شناسه و رفتار مورد انتظار قابلیت‌ها در این پوشه تعریف می‌شود.
- هر پلتفرم Adapter بومی خودش را برای اجرای همان رفتار دارد.
- تغییر هر قابلیت باید وضعیت هر دو پلتفرم را در ماتریس هم‌ارزی به‌روزرسانی کند.
- یک قابلیت تا زمانی که در Android پیاده‌سازی نشده، نباید به‌عنوان آماده نمایش داده شود.

فایل `feature-parity.json` مرجع اولیه‌ی قابلیت‌هاست.

## نگاشت Game Mode

در ویندوز نام قابلیت **Game Mode** است. در Android نام آن **AI Assistant** خواهد بود. هدف مشترک، دستیار آگاه از زمینه‌ی صفحه و آماده‌ی تعامل است؛ اما Android تصویر صفحه را فقط در نشست MediaProjection تأییدشده توسط کاربر دریافت می‌کند.

هم‌ارزی به معنی دور زدن محدودیت‌های سیستم‌عامل نیست. هر قابلیت حساس باید از مجوز رسمی همان پلتفرم استفاده کند.
