Kira dance folder
=================
Put dance files here; Kira picks one at random when music plays (together with her built-in dances).

Supported:
  *.vrma  - VRM Animation files (e.g. from VRoid Hub / Booth, check each file's licence)
  *.fbx   - Mixamo animations

Getting dances from Mixamo (free, needs a free Adobe account):
  1. Open https://www.mixamo.com and sign in.
  2. Search "dance", click an animation (the preview uses a default character).
  3. Download -> Format: FBX Binary (.fbx) -> Skin: "Without Skin" -> Download.
  4. Move the file into this folder. No restart needed: it is picked up the next time a song starts.

Only use files whose licence allows it. Do not redistribute Mixamo files.
