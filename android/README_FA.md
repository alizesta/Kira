# Kira Android

نسخه‌ی اندروید، یک برنامه‌ی Native و مستقل است و برای اجرا به نسخه‌ی ویندوز یا یک سرور واسط اجباری نیاز ندارد.

## ساختار

- `app/`: برنامه‌ی Android با Kotlin و Jetpack Compose
- `MainActivity.kt`: پوسته‌ی اصلی و ناوبری
- `assistant/AiAssistantOverlayService.kt`: حباب شناور دستیار
- `../shared/contracts/feature-parity.json`: قرارداد قابلیت‌های مشترک میان Windows و Android

## ابزار ساخت

- Android Studio با پشتیبانی از Android Gradle Plugin 9.5.x
- JDK 17
- Android SDK Platform 36
- Gradle 9.6.0 یا جدیدتر
- Kotlin 2.4.21
- Jetpack Compose BOM 2026.09.00

پروژه را از پوشه‌ی `android/` در Android Studio باز کن. اگر Gradle Wrapper در محیط توسعه موجود نیست، Gradle 9.6.0 یا جدیدتر را نصب کن و Wrapper را از ریشه‌ی همین پوشه بساز.

## AI Assistant در اندروید

در دسکتاپ، قابلیت Game Mode برای تجربه‌ی بازی و دریافت زمینه‌ی تصویری استفاده می‌شود. معادل پلتفرمی آن در Android با نام **AI Assistant** ساخته می‌شود:

1. دستیار شناور برای دسترسی سریع روی برنامه‌های دیگر
2. درک محتوای صفحه فقط با درخواست و تأیید صریح کاربر
3. فرمان صوتی و تعامل hands-free با رعایت محدودیت‌های سیستم‌عامل
4. ارسال زمینه‌ی انتخاب‌شده به همان مسیر گفتگو و Route

در این مرحله فقط پوسته‌ی Android و حباب شناور پیاده‌سازی شده‌اند. اتصال مدل، Route، حافظه، صوت و MediaProjection هنوز کامل نیست.

## اصل استقلال و هم‌ارزی قابلیت‌ها

- اطلاعات، گفتگوها، تنظیمات و کلیدهای API نسخه‌ی Android روی خود گوشی نگهداری می‌شوند.
- هیچ وابستگی اجباری به برنامه‌ی Windows وجود ندارد.
- قراردادهای مشترک در پوشه‌ی `shared/contracts/` تعریف می‌شوند.
- رفتار هر قابلیت باید بین دو پلتفرم هم‌ارز باشد؛ پیاده‌سازی می‌تواند بومی هر سیستم‌عامل باشد.
- قابلیت‌هایی که Android اجازه‌ی معادل مستقیم آن‌ها را نمی‌دهد باید جایگزین امن و شفاف داشته باشند، نه اینکه ظاهراً فعال اما در عمل بی‌اثر باشند.
